# Ano-Anima

**阿糯 · 一个会记事、有情绪、能自己找点事做的 QQ 分身**

## 这是什么

她把「记忆」当成一件正经事来做：聊过的内容会分层、会淡忘、会在某个瞬间被想起来，
夜里没人说话的时候，她会自己把白天的事重新理一遍。

她的目标是：**过几天回来，她还记得你。**

---

## ✨ 她能做什么

| 能力 | 说明 |
| --- | --- |
| 分层记忆 | 表层 / 整合 / 核心三层，像人一样先记住、再归纳、最后变成"理所当然" |
| 会忘 | 每条记忆有寿命，到期淡出、被想起则延长，重要的能留一年以上 |
| 会想起 | 聊天时按"意思"检索，还会顺着关系网扩散到相关的记忆 |
| 会归纳 | 一段对话结束后，把零散的几件事压成一句话；夜里再重新概括一遍 |
| 有情绪 | 心情、精力、被冷落、被在意，都会影响她回复的长短和语气 |
| 会主动 | 闲久了会自己换签名、发动态、发表情，或者来找你说句话 |
| 会认人 | 按号码认人，不按昵称；记得谁是谁、你该怎么称呼他 |
| 会睡觉 | 有作息，睡着不吵，醒来会先看看昨晚发生了什么 |
| 能接别的平台 | QQ 是默认的，Minecraft 也能接（同一份记忆、同一个她） |

## 🧠 核心是怎么设计的

这一节给想改她、想接别的平台的人看。**只讲思路和公式的形式，具体数字在代码里。**

### 一、三层记忆

```
核心记忆 (core)     不会忘的事：身份、关系、承诺
   ↑ 分数到顶，自动升格
整合记忆 (merged)   一段时间的归纳："这几天他在忙什么"
   ↑ 由多条表层概括出来
表层记忆 (surface)  刚发生的事：谁说了什么、做了什么
```

**关键设计：整合记忆只做"归纳"，不替代原始记忆。**
一条整合记忆统辖若干条表层记忆；表层记忆到期消失后，整合记忆还在，
但它失去了一条依据——这时会在夜里被重新概括，或者被放弃。

### 二、寿命是怎么算的

每条记忆有一个**分数 w（1~10）**，寿命随分数**指数增长**：

```
寿命 = 最小值 × (最大值 / 最小值) ^ ((w - 1) / 9)
```

也就是说：1 分只能活很短，10 分能活一年以上，中间平滑过渡，不是一档一档跳。

**没有"记住/忘记"的开关，只有时间流逝：**

```
剩余 = 寿命 − 已经过的时间
剩余 ≤ 0        → 消失
剩余很少        → 细节和原话先掉，只剩一句话
```

### 三、分数会回落，也会回升

分数不是一次定死的。随着时间推移，一条记忆能"够得着"的分数会一档一档往下掉；
反过来，**被想起来就会回升**——但"被想起来"有两种：

```
只是被联想到（扩散到）  → 寿命延长，不算"这次真提到它"
真被选进对话上下文      → 才算"上次提起"
```

**这个区分很重要**：否则一条老记忆被联想一次，就会被当成"今天聊到的"，反复重新归纳。

### 四、怎么"想起来"

不是关键词匹配，是**向量 + 关系网扩散**：

1. 用这句话算一个向量，找出最像的几条（种子）
2. 从种子出发，沿着"相邻记忆"和"同一个人名下"两条边走几跳（扩散）
3. 每跳一次相关度打折
4. 每一跳里有名额上限，避免一次拽出几十条
5. 排序综合考虑三件事：

```
相关度（语义有多像）
分数（这件事有多重要）
层级（核心 > 整合 > 表层）
```

**结果是：她既能把"你昨天说的那件事"翻出来，也能顺着"你"这个人，把她知道的事都带出来一点。**

### 五、怎么"归纳"

一段对话安静下来之后（她几分钟没说话），会做一次提取：

```
这一步里记几条、记什么，由她自己判断
每条只讲一件事，不许糊在一起
要能独立看懂：谁、什么时候、发生了什么
```

然后每天夜里做一次**复盘**：

```
把这一段的表层记忆压成整合记忆（同一件事合成一条）
重新概括"孩子变了的"整合记忆（把原来那句自己也当一份材料）
把互为子集的整合记忆并掉（一条的孩子全在另一条里 → 就是同一条）
```

### 六、情绪和精力

情绪是**两维**的：愉悦度（不开心 ↔ 开心）和精力（累 ↔ 精神）。

**精力会直接影响她说话：**

```
精力高  → 话多、爱开玩笑
精力低  → 句子短、敷衍，甚至干脆不回
精力耗尽 → 这一句就不说了，等恢复
```

**这不是"规矩"，是她此刻的状态。** 所以你可能会遇到她"懒得理你"——那是设计的一部分。

### 七、平台是插件

```
src/adapters/qq/     QQ 的全部：工具、连接、自主行为
src/adapters/mc/     Minecraft 的工具
src/core/            记忆、情绪、思考（跟平台无关）
src/tools/           跨平台工具（查资料、记忆管理）
```

**判断标准：删掉 `src/adapters/qq/`，她还能思考、还记得事，只是说不了话。**
这就是"平台是插件"的意思。

**接新平台只需要写一个 adapter**：提供一组工具、一段平台提示词（`prompts/<平台>.md`），
再声明自己能做哪些动作。核心代码一行不用改。

## 📦 三种用法

### 一、安装版（推荐给不折腾的人）

下载 `Ano-x.x.x.exe`，双击，中文向导，一路下一步。

装完自动打开浏览器，进入**首次设置页**：

```
一、大模型       聊天 key / 记忆向量 key / 看图 key
二、QQ 连接      协议端地址 / 机器人 QQ 号 / 主人 QQ 号
三、安全         面板密码（手机访问才需要）
四、她是谁       导入现成的人格包，或从空白开始
```

填完点「开始」，她会自动启动。

**卸载**：控制面板里卸载。**程序文件删掉，但 `.data`（她的记忆）会留着**，重装后还是她。

### 二、便携版（解压即用）

解压 `便携版` 文件夹，双击 `启动.bat`，同样会打开首次设置页。
适合放 U 盘，或者装在不想留痕迹的机器上。

### 三、从源码跑

```bash
# 1. 装依赖（只有一个 ws）
npm install

# 2. 复制配置
cp .env.example .env
# 填 LLM_API_KEY / ONEBOT_WS_URL / ONEBOT_SELF_ID / OWNER_QQ

# 3. 启动
node launcher.js
# 面板：http://127.0.0.1:8787
```

**需要一个 OneBot v11 协议端**（SnowLuma / LLOneBot / NapCat 都行），
扫码登录由协议端负责。

## ⚙️ 常用配置

配置都在 `.env` 里，面板「设置」页也能改（改完重启生效）。

| 配置 | 作用 | 默认 |
| --- | --- | --- |
| `LLM_API_KEY` | 聊天用的大模型 | 必填 |
| `LLM_MODEL` | 模型名 | `deepseek-chat` |
| `EMBED_API_KEY` | 记忆向量（可以和上面同一个） | 必填 |
| `VISION_API_KEY` | 看图 | 可选 |
| `ONEBOT_WS_URL` | 协议端地址 | `ws://127.0.0.1:3001` |
| `ONEBOT_SELF_ID` | 机器人 QQ 号 | 必填 |
| `OWNER_QQ` | 主人 QQ 号（只有这个号能授权危险操作） | 必填 |
| `GROUP_REQUIRE_AT` | 群里是否必须 @ 她才回 | `true` |
| `SLEEP_START_HOUR` / `SLEEP_END_HOUR` | 作息 | `1` / `8` |
| `MOOD_COST_REPLY` | 说一句消耗多少精力（%） | `2` |
| `HUMANIZE` | 拟人化（打字延迟、打错字、分条） | `true` |
| `AUTONOMY` | 自主行为总开关 | `false` |
| `WEBUI_PORT` / `BOT_API_PORT` | 面板 / 机器人端口 | `8787` / `8788` |

**完整参数见 `.env.example`，每一项都有注释。**

## 🗂 数据都在哪

```
.data/brain.json        她的记忆（最重要）
.data/roster.json       她认识的人
.data/mood.json         此刻的情绪和精力
.data/persona.md        她是谁
prompts/                提示词：core（通用规则）/ qq / mc
```

**换机器、备份、送人：面板「设置」→「导出人格」**，
得到一个 `.ano` 文件（人设 + 记忆 + 人物表，几百 KB）。
在新机器上「导入人格」，key 重新填一次就行。

**key 不会被打包带走**——那是账号凭据。

## ❓ 常见问题

**她不理我？**
先看精力。精力低了她是真的不想说话，面板上看得到。也可能她在睡觉（作息）。

**她说"不记得"？**
可能那条记忆的寿命到了。记忆会到期消失，这是设计。

**回复很慢？**
拟人化会按字数模拟打字时间，还会偶尔"在忙"。设置里可以关掉 `HUMANIZE`。

**能同时装两个吗？**
可以，改 `WEBUI_PORT` / `BOT_API_PORT`，并用不同的 QQ 号。

**能接微信 / Discord 吗？**
核心是平台无关的，写一个 adapter 就行。目前只做了 QQ 和 MC。
